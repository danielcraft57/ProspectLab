# Design ProspectLab

Les maquettes UX/UI locales vivent dans `design/mockups/` (dossier **gitignoré**).

## Ouvrir

```text
design/mockups/index.html
```

## Regenerer

```powershell
python scripts/generate_ui_mockups.py
```

## Contenu

- Tokens Material Design 3 (dark + variante light)
- Shell app, rail patterns, FAB etendu, sheets, dialogs, steppers, kanban
- Graphiques offline (`charts.css`) : line, bars, donut, heatmap, funnel, radar, slope, bullet, treemap, lollipop, candles, sparklines
- ~30 ecrans : dashboard, entreprises, fiche, analyses, scrapers, campagnes, bounces, login, restricted, etc.
- Variantes Campagnes Brevo (`campagnes-brevo/`)

## Branche

`feature/ui-material-mockups`
